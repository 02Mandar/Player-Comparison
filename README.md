# Player Performance Comparison System

## Overview
This project compares cricket players with cricket players and football players with football players using sports analytics and performance metrics.

## Features
- Same sport player comparison
- Cricket analytics dashboard
- Football analytics dashboard
- Performance score calculation
- Win percentage analysis
- Graph visualization
- CSV dataset handling

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files Included
- comparison.py
- player_comparison.csv
- requirements.txt
